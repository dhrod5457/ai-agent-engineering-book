## 현재 확인

Latest explicitly published version:
- 0.3.0

A2A scope:
- interoperability between independent agent systems
- capability discovery
- interaction/message exchange
- collaborative task lifecycle
- artifact exchange
- authentication / authorization integration

Current TaskState values:
- submitted
- working
- input-required
- completed
- canceled
- failed
- rejected
- auth-required
- unknown

Agent Card:
- discovery and capability metadata
- security schemes may be declared
- discovery itself is not authorization

## 본문 정책

Protocol object를 internal domain object와 동일시하지 않는다.

~~~text
A2A Task
≠ MCP Task
≠ Factory Task
~~~

본문은 exact wire syntax보다 responsibility boundary를 중심으로 유지한다.
