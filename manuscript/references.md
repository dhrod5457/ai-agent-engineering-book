## External Source IDs

~~~text
S-*
= official / protocol / vendor engineering / research / preprint source
~~~

현재 Source ID의 canonical name과 Evidence Class는 planning/source-catalog.md에서 관리한다.

최종 출판 단계에서 이 파일에 다음 bibliography metadata를 materialize한다.

- author / organization
- title
- publication date
- version / revision
- venue
- canonical URL
- accessed / verified date
- source class
- limitation note

## Book Synthesis IDs

~~~text
B-*
= 이 책의 synthesis / framework
~~~

B-*는 외부 문헌 citation이 아니다.

현재:
- B-AGENT-CAPABILITY
- B-STATE-PLANE
- B-CONTEXT-PROJECTION
- B-MEMORY-WRITE-GATE
- B-RISK-PROFILE
- B-AGENT-VERSION
- B-HARNESS-DEBT
- B-OWNERSHIP
- B-FACTORY-BOUNDARY

최종 원고에서는 최초 정의 시 "이 책에서는 ..."으로 명확히 표시한다.
