# Epilogue. Agent를 더 똑똑하게 만드는 것보다 시스템을 더 믿을 수 있게 만든다

## Goal
책의 핵심 메시지를 Model 중심 사고에서 System 중심 사고로 다시 압축한다.

## Core Claims
- Model은 계속 좋아지지만 production responsibility는 사라지지 않는다.
- 더 강한 Model은 일부 Harness를 없앨 수 있지만 State, Identity, Verification의 필요를 자동으로 없애지 않는다.
- Agent Engineering의 목표는 최대 자율성이 아니라 필요한 자율성을 통제 가능한 구조 안에 두는 것이다.
- 하나의 Agent를 신뢰할 수 있게 만든 뒤 그 위에서 Software Factory로 확장한다.

## Flow
1. 책 시작의 Model vs Agent 질문 회수
2. Harness가 변하는 이유
3. 오래 남는 boundary
4. Control before Autonomy
5. Agent State Plane → Factory Control Plane
6. 다음 단계

## Final Message
> 좋은 Agent 시스템은 모델을 무조건 믿는 시스템이 아니라, 모델을 덜 믿어도 실제 일을 맡길 수 있는 시스템이다.
